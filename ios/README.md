# ZI Gate для iPhone

Нативное приложение **SwiftUI**, iOS **16+**. Тот же смысл, что у Android: зоны шлагбаумов, GPS, звонок на номер ворот.

## Важно про автозвонок

Apple **не даёт** приложению самому набирать номер из фона (аналог Android `ACTION_CALL` из сервиса запрещён).

Как сделано на iPhone:

1. Геозоны Core Location (до 20 шлагбаумов).
2. Вход в зону → **уведомление** «Позвонить».
3. Если приложение открыто — набор `tel:` стартует сразу.
4. Тап по иконке на карточке — ручной звонок.

Список шлагбаумов в **том же JSON**, что на Android: кнопка «Загрузить / Отправить» → копировать / вставить.

## Сборка на Mac

```bash
open ios/ZIGate/ZIGate.xcodeproj
```

1. Xcode → Signing & Capabilities → ваш **Team**.
2. Bundle ID: `by.zakharevich.zigate` (или свой, если ID занят).
3. На устройстве: Геопозиция = **Всегда**, уведомления включены.
4. Product → Run (на iPhone; симулятор не звонит).

IPA для TestFlight: Product → Archive.

## Разрешения

| Permission | Зачем |
|---|---|
| Location Always | геозоны при заблокированном экране |
| Notifications | кнопка «Позвонить» при въезде |
| Background location | не выгружать трекинг |

Минимум iOS 16, только iPhone.
